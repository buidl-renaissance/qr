# QR

Generate and style QR codes — modules, eyes, colors, gradients, logo — then download PNG or SVG.

## Setup

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (Pages Router) + TypeScript
- styled-components
- [qr-code-styling](https://qr-code-styling.com)
